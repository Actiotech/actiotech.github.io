CAREERS AT ACTIOTECH

QA Engineer

with Test Automation focus

Job Description

We’re looking for a QA Engineer who can test applications using test data generated based on requirement specifications, with strong expertise in scripting and automation frameworks such as Playwright.

Responsibilities

We’ll be a great team together if you :

  • Design and execute test plans based on requirement specifications
  • Generate and manage test data driven by functional and non-functional requirements
  • Build and maintain end-to-end test automation suites using Playwright
  • Develop and maintain automation scripts for regression, smoke, and integration testing
  • Collaborate with developers and product teams to ensure comprehensive test coverage
  • Identify, document, and track defects through resolution
  • Continuously improve QA processes, tools, and test infrastructure
Preferred Qualifications
  • Bachelor’s or Masters degree in Computer Science or related field
  • 3+ years of professional QA or test automation experience
  • Strong scripting skills in JavaScript/TypeScript
  • Hands-on expertise with Playwright for browser-based test automation
  • Experience generating test data from requirement specifications and user stories
  • Familiarity with CI/CD pipelines and integrating automated tests into build workflows
  • Experience with API testing tools (Postman, REST Assured, or similar)
  • Knowledge of test management and defect tracking tools (Jira, TestRail, or similar)
  • Excellent written and oral communication skills in English
